# Service Finder

Service Finder is an optional Laravel module for map/search-based coverage
content. It is currently disabled for the Bridgeway Digital local setup and is
not required for the active Next.js frontend routes.

Active dynamic Bridgeway content is managed through:

- CMS content pages
- CMS service pages
- blog listing/detail records
- navigation, footer and site settings
- inquiry/contact submissions

If Service Finder is re-enabled later, keep its copy and map settings in the
admin settings table and avoid hardcoded business data in the frontend.
